Discover CODE QUEST, a simple RPG video game written with C# that runs in the programming console.

|Chapter 1| Chapter 2 | Chapter 3|
|---|---|---|

| - Choose your mage name| - Enter into the Dungeon of a Dragon| - It is mining time|

| - Gain power points while training <br> and level up|- Do not be unlucky, you have 3 tries to guess the code. <br> Otherwise, the dragon will get angry|-Gain a fortune in bits or gain <br> nothing if you are unlucky enough|

## How to play ❔
1. Download the folder "CodeQuest" from the main branch.
2. Open the folder program.csproj in your favorite code editor. <br> Alternatively, copy the code from the program.cs file and paste it into a new project.
3. Execute the code in the programming console and enjoy playing while following the game rules 😀.
   
‼️IMPORTANT‼️: If you play by executing the game in the .csproj file, make sure that your .NET version matches the one from your code editor.
